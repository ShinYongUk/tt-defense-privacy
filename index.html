Alice: Defense 개인정보 처리방침

시행일: 2026년 10월 16일

YongHyeseung(이하 "개발자")은 Alice: Defense(이하 "게임")를 제공하면서 아래와 같이 개인정보를 처리합니다.

1. 수집 항목과 저장 위치

게임은 이용자가 '플레이 데이터 수집'에 동의한 경우에만 Unity Analytics로 다음 분석 정보를 수집합니다.

  • 기기·앱 정보: 무작위로 생성된 설치 식별자, 기기 종류, 운영체제, 게임 버전, 언어 설정, IP 주소(국가·지역 수준의 대략적인 위치 추정에만 사용), iOS의 경우 IDFV
  • 플레이 기록: 게임 실행·종료 시각과 플레이 시간, 튜토리얼 진행 단계, 판 시작·종료(게임 모드, 챕터, 결과, 도달 스테이지, 소요 시간, 누적 판 수), 스테이지 결과, 주요 기능의 첫 사용 여부

분석 정보와 별도로, 서버 기능을 이용할 때 Unity Gaming Services의 Authentication, Cloud Code, Cloud Save를 통해 다음 정보를 처리합니다. 분석 정보 수집을 끄더라도 계정 인증과 서버 기능에 필요한 데이터 처리는 별개입니다.

  • 계정 정보: Unity Authentication Player ID와 인증·세션 정보. 외부 계정을 연결하지 않은 게스트 계정에도 서버 계정 식별자가 발급됩니다.
  • Android에서 Google Play Games 연결을 이용하는 경우: Google Play Games 계정 식별자와 서버 인증 코드 등 연결·인증에 필요한 정보
  • 서버 게임 데이터: 재화, 보유 항목, 뽑기 결과와 관련 상태, 패스·VIP·출석 상태, 보상 수령 상태, 중복 처리를 방지하기 위한 요청 식별자·처리 결과와 관련 시각·진행 상태
  • 서비스 이용에 필요한 네트워크 정보: IP 주소 등 Unity 서비스가 처리하는 접속 정보

게임 진행 및 설정 정보의 일부는 이용자의 기기에 저장됩니다. 계정과 연결된 서버 게임 데이터는 Cloud Code에서 처리하고 Cloud Save에 저장하므로, 모든 진행 정보가 기기에만 저장되는 것은 아닙니다. 이 안내는 게임의 모든 진행 정보가 서버에 백업·동기화된다는 뜻은 아닙니다.

게임 계정 기능은 별도의 이름·이메일·전화번호 입력을 요구하지 않습니다. 다만 문의나 삭제 요청을 이메일로 보내면 회신 이메일 주소와 문의 내용, 계정 확인에 필요한 최소한의 정보를 처리합니다.

2. 이용 목적

  • 분석 정보: 통계 형태로 분석하여 난이도 조정, 튜토리얼과 화면 개선, 오류 파악 등 게임 개선에 사용합니다. 광고나 맞춤형 마케팅에는 사용하지 않습니다.
  • 계정·서버 게임 데이터: 게임 계정 인증과 외부 계정 연결, 재화·보유 항목 관리, 뽑기·보상·패스·VIP·출석 기능 제공, 중복 처리 방지와 게임 데이터의 일관성 확인에 사용합니다.
  • 문의 정보: 문의 응대, 계정 확인, 열람·정정·삭제 요청 처리와 결과 안내에 사용합니다.

3. 처리 위탁 및 국외 이전

  • 수탁자: Unity Technologies (Unity Gaming Services – Analytics, Authentication, Cloud Code, Cloud Save)
  • 이전 국가: Unity가 운영하는 서버 소재 국가(미국 등)
  • 이전 항목: 각 기능에 필요한 1항의 분석 정보, 계정·인증 정보, 서버 게임 데이터와 접속 정보
  • 이전 시기와 방법: 해당 기능 이용 중 네트워크를 통해 전송(HTTPS 암호화)
  • 보유·삭제: 분석 정보와 계정·서버 게임 데이터를 구분하여 4항에 안내합니다.
  • Unity 개인정보 처리방침: https://unity.com/legal/game-player-and-app-user-privacy-policy

Google Play Games 연결을 이용하는 경우 Google 서비스의 정보 처리는 Google 개인정보처리방침도 적용됩니다.

4. 보유 및 파기

Unity Analytics로 수집된 분석 정보는 기존 안내와 같이 수집일로부터 13개월 동안 보관한 뒤 자동으로 삭제됩니다. 이용자가 분석 정보 수집 동의를 철회하면 수집을 중단하고, 서비스 연결이 준비되면 저장된 분석 정보의 삭제를 Unity에 요청합니다.

Unity Authentication 계정과 Cloud Save 서버 게임 데이터는 분석 정보와 별도로 관리·삭제됩니다. 분석 정보 수집 동의 철회나 분석 데이터 삭제 요청만으로 게임 계정과 서버 게임 데이터 전체가 삭제되는 것은 아닙니다.

삭제 대상은 게임 계정과 연결된 서버 저장 데이터(재화, 보유 항목, 뽑기·패스·VIP·출석 상태 등), 관련 개인정보 및 연결된 분석 데이터입니다. 삭제된 계정과 게임 데이터는 복구할 수 없습니다. Google 계정 자체는 삭제되지 않습니다.

삭제 요청을 받으면 본인 확인 등 필요한 절차를 거쳐 지체 없이 처리하며, 요청일로부터 10일 이내에 처리 결과를 안내합니다. 법령상 보관이 필요한 정보는 해당 법령에서 정한 기간 동안 보관하고, 그 항목과 근거를 안내합니다.

5. 이용자의 권리와 계정 삭제 요청

게임 설정의 '개인정보' 항목에서 '플레이 데이터 수집'을 끄면 언제든 분석 정보 수집 동의를 철회할 수 있습니다. 이전에 동의하고 수집을 허용한 상태에서 끄면 분석 데이터 삭제도 요청됩니다. 서비스가 준비되지 않은 경우 삭제 요청은 준비된 뒤 전송됩니다.

계정과 관련 데이터 삭제를 원하시면 dyddyddnr@naver.com으로 이메일을 보내 주세요. 제목은 ‘Alice: Defense 계정 삭제 요청’으로 하고, 이용 플랫폼·로그인 방식·알고 있는 경우 Player ID를 적어 주세요. Player ID를 모르거나 앱을 삭제한 경우에도 이메일로 문의할 수 있습니다. 계정 확인에 필요한 최소한의 추가 정보는 개별 안내합니다. 비밀번호·인증번호·로그인 토큰·신분증은 보내지 마세요.

Alice: Defense Privacy Policy

Effective date: October 16, 2026

YongHyeseung ("we") processes personal information as described below when providing Alice: Defense (the "Game").

1. Data we process and where it is stored

Only if you agree to "Gameplay Data Collection," the Game collects the following analytics data through Unity Analytics:

  • Device and app information: a randomly generated installation ID, device model, operating system, game version, language setting, IP address (used only to estimate an approximate country or region), and IDFV on iOS
  • Gameplay records: session start and end times and play time, tutorial progress, run start and end (game mode, chapter, result, stage reached, duration, number of runs played), stage results, and first use of main features

Separately from analytics, server features process the following data through Unity Gaming Services Authentication, Cloud Code, and Cloud Save. Turning off analytics collection is separate from the data processing needed for account authentication and server features.

  • Account information: the Unity Authentication Player ID and authentication and session information. Guest accounts without an external account connection also receive a server account identifier.
  • If you use Google Play Games linking on Android: the Google Play Games account identifier, server authentication code, and other information needed for linking and authentication
  • Server game data: currencies, owned items, draw results and related state, pass, VIP and attendance state, reward claim state, and request identifiers, processing results, and related timing and progress state used to prevent duplicate processing
  • Network information needed to use the services: connection information such as IP addresses processed by Unity services

Some game progress and settings are stored on your device. Server game data associated with an account is processed by Cloud Code and stored in Cloud Save, so not all progress information is stored only on your device. This does not mean that all game progress is backed up or synchronized to the server.

The game account features do not require you to separately enter a name, email address, or phone number. If you email an inquiry or deletion request, we process your reply email address, the contents of your request, and the minimum information needed to verify the account.

2. How we use data

  • Analytics data: analyzed in aggregate to improve the Game, such as adjusting difficulty, improving the tutorial and screens, and finding errors. We do not use it for advertising or targeted marketing.
  • Account and server game data: to authenticate game accounts and link external accounts, manage currencies and owned items, provide draw, reward, pass, VIP and attendance features, prevent duplicate processing, and check game data consistency.
  • Inquiry information: to respond to inquiries, verify accounts, handle access, correction and deletion requests, and communicate the outcome.

3. Service provider and international transfer

  • Provider: Unity Technologies (Unity Gaming Services – Analytics, Authentication, Cloud Code, Cloud Save)
  • Countries: where Unity operates its servers (including the United States)
  • Data: the analytics data, account and authentication information, server game data, and connection information listed in Section 1, as needed for each feature
  • When and how: sent over the network when the relevant features are used (encrypted with HTTPS)
  • Retention and deletion: analytics data is distinguished from account and server game data in Section 4.
  • Unity's privacy policy: https://unity.com/legal/game-player-and-app-user-privacy-policy

If you use Google Play Games linking, Google's processing of information for its services is also covered by the Google Privacy Policy.

4. Retention and deletion

As previously stated, analytics data collected through Unity Analytics is kept for 13 months after collection and then deleted automatically. If you withdraw analytics consent, collection stops and we request deletion of the stored analytics data from Unity once the service connection is ready.

Unity Authentication accounts and Cloud Save server game data are managed and deleted separately from analytics data. Withdrawing analytics consent or requesting analytics data deletion does not by itself delete the game account and all server game data.

Deletion covers the game account and its associated server-stored data (including currencies, owned items, and draw, pass, VIP, and attendance state), related personal information, and linked analytics data. Deleted accounts and game data cannot be recovered. Your Google account itself will not be deleted.

After receiving a deletion request, we will process it without delay following the necessary steps, including identity verification, and inform you of the outcome within 10 days of the request date. Information that must be retained by law will be kept for the period required by the applicable law, and we will explain which information is retained and the legal basis.

5. Your rights and account deletion requests

You can withdraw analytics consent at any time by turning off "Gameplay Data Collection" under "Privacy" in the Game's Settings. Turning it off after previously granting consent and allowing collection also requests analytics data deletion. If the service is not ready, the deletion request is sent once it is ready.

To request deletion of your account and associated data, email dyddyddnr@naver.com. Use the subject “Alice: Defense account deletion request” and include your platform, sign-in method, and Player ID if you know it. You can contact us by email even if you do not know your Player ID or have uninstalled the app. We will individually advise you of any minimal additional information needed to verify your account. Do not send passwords, verification codes, sign-in tokens, or identity documents.
